# Roadmap

Gates are hard: a phase starts only when the previous gate passes.

| Phase | Deliverable | Gate to pass |
|---|---|---|
| 1 Research ✅ | Market, scoring, competitors, economics, payment & compliance research | — |
| 2 Validation | Manual Trends/Reddit/TikTok evidence; CJ live quotes; supplier answers; sample ordered | **Founder approves niche, name shortlist, sample spend** |
| 3 Professional review | CA consult on GST/FEMA/purpose code | Written answers on file |
| 4 Brand | Final name (TM + domain check), visual guidelines, copy | Name approved |
| 5 Storefront | OS 2.0 theme in `/theme`, tested on free dev store | Sample passes checklist |
| 6 Operations | Order, refund, support workflows + templates | — |
| 7 Content engine | 30 ideas / 15 scripts / calendar — filmed with real sample | Sample in hand |
| 8 Payments | PayPal (± Razorpay) approved | Approval + founder go-ahead |
| 9 Launch | Paid Shopify plan, policies live, password removed | All `docs/launch-readiness.md` items green |
| 10 First 30 days | Weekly reviews; scale / fix / kill at day 30 | Positive contribution verified on real orders |
