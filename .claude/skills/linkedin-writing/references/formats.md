# Post formats and their styles

| Format | Tone | Typical length | Structure notes | Pair with skill |
|---|---|---|---|---|
| Educational | Calm, clear, teacher-like | 900–1,300 chars | Concept → why it matters → 3 steps → takeaway | technical-explainer |
| Technical | Precise, concrete | 900–1,500 | Observation → mechanism → example/code idea → trade-off | technical-explainer |
| Storytelling | Narrative, scene-first | 1,000–1,600 | Scene → tension → turn → lesson | storytelling |
| Opinion | Direct, confident, fair | 700–1,200 | Claim → evidence → counter → stance | controversial-angle |
| Controversial analysis | Balanced, rigorous | 1,000–1,600 | Debate framing → both sides → defensible position → question | controversial-angle |
| Build in public | Transparent, specific | 700–1,200 | What I'm building → what happened → numbers (owner-supplied only) → next | storytelling |
| Founder lessons | Reflective, practical | 800–1,300 | Situation → mistake → lesson → rule | storytelling |
| Business breakdown | Analytical | 1,000–1,600 | Company → model → why it works/fails → lesson | business-analysis |
| AI experiment | Curious, hands-on | 800–1,400 | Hypothesis → setup → result → what surprised me | technical-explainer |
| Case study | Evidence-heavy | 1,000–1,600 | Context → action → outcome (sourced) → transferable lesson | business-analysis |
| Problem-solution | Practical | 700–1,200 | Problem → hidden cost → root cause → fix | business-analysis |
| Industry analysis | Big-picture, sourced | 1,000–1,600 | Shift → evidence → implications → who wins/loses | business-analysis |

Build in public, founder lessons, AI experiments, and storytelling **depend on owner-supplied facts**. Without them, produce a template with `[OWNER INPUT NEEDED]` markers and route it to review.
