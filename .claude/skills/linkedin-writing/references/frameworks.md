# Writing frameworks

| ID | Name | Flow | Best for | Watch out for |
|---|---|---|---|---|
| F1 | Belief flip | Popular belief → Counterpoint → Evidence → New perspective | Opinion, controversial analysis | Straw-manning the popular belief. State it fairly. |
| F2 | Curiosity gap | Unexpected observation → Curiosity → Explanation → Payoff | Technical, AI experiments, industry analysis | The payoff must be real and arrive in the post, not "in comments". |
| F3 | Hidden cost | Problem → Hidden cost → Root cause → Solution | Problem-solution, business breakdowns | Costs need a source or must be framed as an illustrative estimate. |
| F4 | Argued opinion | Strong opinion → Evidence → Counterargument → Conclusion | Opinion, founder decisions | Must steelman the counterargument. |
| F5 | Lesson | Personal experience → Failure → Learning → Actionable lesson | Founder lessons, build in public | **Requires owner-supplied experience.** Never fabricate. Without input, use `[OWNER INPUT NEEDED]` and send to review. |
| F6 | Visual-led | Surprising visual → Strong headline → Explanation → Insight | Image and carousel posts | The visual must carry one message that is readable at phone size. |

## Skeletons

**F1**
```
Everyone says {belief}.
I think that's {incomplete/wrong} — here's why.
{evidence 1 with source}
{evidence 2}
The better way to think about it: {new perspective}.
```

**F2**
```
{specific surprising observation}.
{why that's strange}
Here's what's actually happening: {explanation}
{payoff — what the reader can do or now understands}
```

**F3**
```
{problem in reader's words}
The visible cost is {x}. The hidden cost is {y}.
Root cause: {cause}.
What works instead: {2–3 concrete steps}
```

**F4**
```
{opinion in one sentence}.
{evidence}
The strongest argument against this: {counterargument, fairly stated}.
Where I land: {conclusion with nuance}.
```
