# Visual Design

## Purpose
Create a visual that stops the scroll *and* carries the post's single message, readable on a phone in under two seconds.

## Instructions
- **One message per visual.** If the visual needs a paragraph to explain itself, redesign it.
- **Three concepts per post:**
  - **A: Editorial typography poster.** Large type, Swiss-inspired grid, high contrast. Rendered with HTML/CSS.
  - **B: Cinematic AI/tech image.** Artwork from the image model. Any text is overlaid with HTML/CSS, never generated by the image model.
  - **C: Educational infographic/comparison.** Diagram, data chart, or side-by-side. Rendered with HTML/CSS. Data only from the brief, with the source in the footer.
- **Text goes in HTML/CSS, never in image-model output.** Image models still misspell words.
- Follow the design tokens in `references/design-system.md`: type scale, colours, spacing, safe margins.
- **No generic AI imagery:** no glowing brains, blue robot hands, handshake-with-robot, matrix rain, or floating holographic padlocks.
- **Sizes:** 1080×1350 (4:5 portrait, preferred for feed), 1080×1080, 1200×627 (link-style landscape).
- **Mobile readability:** headline ≥ 64px at 1080 width; body ≥ 32px; contrast ratio ≥ 4.5:1 for body and ≥ 3:1 for large text.
- Include a small, consistent brand mark (owner name or handle). Do not use logos of other companies unless discussing them factually, and never in a way that implies endorsement.

## Workflow
1. Extract the single message (≤ 8 words) and the supporting line (≤ 15 words).
2. Choose a style per concept: premium editorial, modern minimal, Swiss typography, high-contrast, cinematic tech, business magazine, data visualization, or glassmorphism (sparingly).
3. For A and C, write the layout spec (grid, hierarchy, tokens, content).
4. For B, write the image prompt (subject, composition, lighting, lens, palette, negative list) and leave a text-free zone for the overlay.
5. Render (backend: Playwright for HTML; OpenAI Images for artwork).
6. **Validate:** dimensions, contrast, minimum font size, text overflow, focal point, legibility at 375px width, typo check on the rendered text, and a vision review.
7. Score with the Visual Quality Score: hierarchy 20, mobile readability 20, topic relevance 20, design quality 15, originality 15, brand consistency 10.

## Reusable prompts
**Concepts**
```
Post message: {message}. Supporting line: {support}. Data available: {data}.
Create 3 concepts (A editorial typography, B cinematic tech, C infographic).
For each: style, focal point, hierarchy (H1/H2/meta), colour tokens, layout spec,
and for B an image prompt with a clean negative-space area for text overlay.
Avoid: glowing brains, robot hands, matrix code, generic stock-tech.
```
**Image prompt template (concept B)**
```
{subject}, {composition: rule of thirds, subject left, clean negative space right},
{lighting: soft directional / rim light}, {lens: 35mm, shallow depth of field},
{palette: from brand tokens}, editorial photography style, high detail.
No text, no letters, no logos, no watermarks.
```
**Visual QA (vision)**
```
Review this image as it would appear on a phone feed (375px wide).
Is the main message readable in 2 seconds? Any typos, cut-off text, low contrast,
clutter, or generic AI clichés? Score hierarchy, readability, relevance, design, originality, brand (0-10).
```

## Examples
### Good
Concept A for "Your AI agent needs fewer tools": off-white background, a huge black "FEWER TOOLS." on the left grid column, a small list "20 tools → 3 tools" in mono below, brand handle bottom-left, source bottom-right.

### Bad
A blue glowing robot shaking hands with a businessman, with the image model rendering "AI AGENTS ARE THE FUTRE" in the sky. Cliché imagery and a misspelling.

## Quality checklist
- [ ] One message; readable at 375px in about 2 seconds
- [ ] All text rendered via HTML/CSS and spell-checked
- [ ] Contrast ≥ 4.5:1 body / 3:1 large; headline ≥ 64px at 1080w
- [ ] Correct dimensions; nothing cut off; safe margins respected
- [ ] No generic AI imagery
- [ ] Data in visual matches brief; source shown
- [ ] Brand mark present and consistent
