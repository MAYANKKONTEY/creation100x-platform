# Design system (v0, to be refined with the owner in M5)

## Tokens
| Token | Value | Use |
|---|---|---|
| `--ink` | `#0E0E10` | Primary text, dark backgrounds |
| `--paper` | `#F5F3EE` | Light backgrounds (warm off-white) |
| `--accent` | `#FF5A1F` | One accent per visual, for emphasis only |
| `--muted` | `#6B6B70` | Meta text (on paper: 5.2:1 contrast) |
| `--line` | `#D9D6CF` | Rules, dividers |
| `--signal` | `#2F6BFF` | Data highlight (charts) |

## Type
- Display: Inter Tight / Inter, weight 800, tracking −2%.
- Body: Inter 400/500.
- Mono (data, code): JetBrains Mono.
- Scale at 1080 width: H1 96–140px · H2 48–64px · body 32–40px · meta 24–28px.

## Grid
- 12-column grid, 72px outer margins, 24px gutters.
- Safe area: keep text 72px inside every edge.
- Brand mark: bottom-left, meta size. Source: bottom-right, meta size.

## Styles
| Style | Character |
|---|---|
| Premium editorial | Serif display option, generous whitespace, magazine rhythm |
| Modern minimal | One element, lots of space |
| Swiss typography | Strict grid, flush-left, big type, rules |
| High contrast | Ink/paper inversion, accent for one word |
| Cinematic tech | Dark photographic artwork, text in negative space |
| Business magazine | Headline + deck + pull-number |
| Data visualization | One chart, one takeaway as title |
| Glassmorphism | Only over artwork, blur ≤ 24px, text still ≥ 4.5:1 |
